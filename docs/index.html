How installing a tool works

  1. Open Available tools: each tool shows Not installed, Installed, Update available or No release yet.
  2. Press Install. The launcher downloads the tool's installer from its own release page, without an account or token.
  3. It checks the download's size and SHA-256 digest against the release, and discards it if either differs.
  4. The tool's own installer runs and shows that tool's license for you to accept.

Installed tools launch from the same window, offline too.
